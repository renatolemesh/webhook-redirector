Para onde vai este canal?

Marque quantos quiser: cada um recebe uma cópia dos eventos. Só aparecem os que recebem o formato da Meta. Um endpoint que aponta para a caixa de outro número passa a receber este também.
Cria a caixa pela API e a rota para ela. As credenciais vêm do endpoint Connect escolhido.
Usado uma vez, não fica guardado.
